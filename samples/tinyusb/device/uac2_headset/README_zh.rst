UAC2 耳机
======================================================

概述
------

本示例工程实现一个带立体声扬声器和麦克风功能的 USB 音频耳机。

- PC 通过 USB 发送的播放音频数据，经开发板的 I2S 接口和音频 Codec 输出。

- 开发板音频 Codec 采集的音频数据作为麦克风数据发送给 PC。

- 耳机使用 48 kHz、双声道、24 位（32 位时隙）音频格式；在高速模式下枚举为 UAC2，在全速模式下枚举为 UAC1。

- PC 可控制扬声器和麦克风的静音与音量。设备以 UAC1 运行时，按下板载按键可在 10% 和 100% 扬声器音量之间切换。

硬件设置
------------

- 使用 USB Type-C 线缆连接 PC USB 端口和开发板的 PWR DEBUG 端口。

- 使用 USB Type-C 线缆连接 PC USB 端口和由 ``BOARD_TUD_RHPORT`` 选择的开发板 USB device 端口。

- 将扬声器或耳机，以及麦克风连接至开发板的音频 Codec 接口。

工程配置
------------

- ``src/tusb_config.h`` 中的 ``BOARD_TUD_RHPORT`` 用于选择 USB device 控制器。设置为 ``0`` 表示使用 USB0；对于提供 USB1 的开发板，设置为 ``1`` 表示使用 USB1。默认使用 USB0。

- USB 音频格式、端点间隔和缓冲区大小可在 ``src/tusb_config.h`` 中配置。修改这些配置后，需同步更新 USB 描述符。

- 本示例依赖 I2S 音频 Codec，仅适用于声明了 ``i2s`` 和 ``board_audio_codec`` 依赖的开发板。

运行现象
------------

工程正确运行后，串口终端将输出：

.. code-block:: console

   Headset running

1. 打开 PC 声音设置，将 ``TinyUSB Headset`` 分别选择为播放设备和录音设备。

2. 在 PC 上播放音频，连接到开发板的扬声器或耳机将输出相应声音。

3. 在 PC 上打开录音软件，选择 ``TinyUSB Headset`` 作为输入设备。对连接到开发板的麦克风说话，完成录音后播放录音内容。

4. 在 PC 声音设置中调节播放或麦克风音量，或对任一路径静音，以验证音频控制功能。
